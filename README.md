## Sobre mim

Atuo como **Platform Engineer no setor bancário**, compondo o time de **Data Foundation**. Trabalho na construção, evolução e sustentação de uma plataforma de dados em cloud, em um ambiente regulado que exige segurança, rastreabilidade, governança e alta confiabilidade operacional.

No dia a dia, combino **AWS, Kubernetes/EKS, Crossplane, Terraform, Python, GitHub Actions e engenharia de software** para criar automações, pipelines, componentes de infraestrutura e serviços de plataforma que apoiam múltiplas equipes internas no consumo e compartilhamento seguro de dados.

Minha trajetória passa por **engenharia de software, dados, cloud e segurança da informação**. Esse cruzamento é o que define meu perfil: alguém que entende código, infraestrutura, governança, operação e o impacto disso em plataformas corporativas.

> Meu foco é tornar plataformas de dados mais seguras, automatizadas, escaláveis e fáceis de operar.
